#4 대용량 Excel 스트리밍

SXSSF를 이용한 대용량 Excel 생성 (메모리 효율적)

사용 클래스: StreamingExcelWriter (SXSSF)
대용량 데이터도 메모리 문제 없이 처리
Code Example 
// Excel 생성 예제
try (ExcelWriter writer = new ExcelWriter()) {
    List<List<Object>> data = new ArrayList<>();
    data.add(Arrays.asList("ID", "Name", "Email"));
    data.add(Arrays.asList(1, "John", "john@example.com"));

    writer.write("Sheet1", data);
    writer.save(Path.of("output.xlsx"));
}

// Excel 읽기 예제
try (ExcelReader reader = ExcelReader.open(Path.of("input.xlsx"))) {
    List<Map<String, Object>> data = reader.readAsMap();
    data.forEach(row -> System.out.println(row));
}

// 대용량 스트리밍 예제
try (StreamingExcelWriter writer = new StreamingExcelWriter()) {
    for (int i = 0; i < 100000; i++) {
        writer.writeRow("Sheet1", Arrays.asList(i, "Data " + i));
    }
    writer.save(Path.of("large.xlsx"));
}
