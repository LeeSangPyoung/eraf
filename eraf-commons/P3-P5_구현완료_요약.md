## 🎯 P3 구현 항목 (6개)

### 1. API Versioning (eraf-web)
**구현 내용**:
- `@ApiVersion` 어노테이션
- 4가지 버전 관리 전략 지원
  - URI: `/v1/users`, `/v2/users`
  - Header: `API-Version: 1.0`
  - Parameter: `/users?version=1.0`
  - Media Type: `application/vnd.api.v1+json`

**주요 클래스**:
- `com.eraf.web.version.ApiVersion`
- `com.eraf.web.version.VersionStrategy`
- `com.eraf.web.version.ApiVersionRequestCondition`

### 2. IP Access Control (eraf-security)
**구현 내용**:
- IP 화이트리스트/블랙리스트
- CIDR 표기법 지원 (`192.168.1.0/24`)
- Proxy 헤더 지원 (`X-Forwarded-For`, `X-Real-IP`)
- Servlet Filter 통합

**주요 클래스**:
- `com.eraf.security.ip.IpValidator`
- `com.eraf.security.ip.IpAccessControlFilter`
- `com.eraf.security.ip.IpAccessControlProperties`

### 3. Cursor-based Pagination (eraf-data-jpa)
**구현 내용**:
- 커서 기반 무한 스크롤
- O(1) 성능 (Offset 방식은 O(n))
- Base64 커서 인코딩
- JPA Repository 통합

**주요 클래스**:
- `com.eraf.jpa.cursor.CursorPage`
- `com.eraf.jpa.cursor.CursorPageBuilder`
- `com.eraf.jpa.cursor.CursorRequest`

### 4. OpenTelemetry Integration (eraf-observability) ⭐
**구현 내용**:
- 분산 추적 (Distributed Tracing)
- 메트릭 수집 (Counter, Histogram, Gauge, UpDownCounter)
- OTLP Exporter (Jaeger, Zipkin 연동)
- Auto-instrumentation

**주요 클래스**:
- `com.eraf.observability.TracingUtil`
- `com.eraf.observability.MetricsUtil`
- `com.eraf.observability.ErafObservabilityAutoConfiguration`

**설정 예시**:
```yaml
eraf:
  observability:
    enabled: true
    service-name: my-service
    exporter:
      endpoint: http://localhost:4317
```

### 5. Webhook Integration (eraf-notification)
**구현 내용**:
- Slack Incoming Webhook
- Microsoft Teams Webhook
- 메시지 템플릿
- 첨부 파일 및 액션 버튼 지원

**주요 클래스**:
- `com.eraf.notification.webhook.SlackWebhookSender`
- `com.eraf.notification.webhook.TeamsWebhookSender`
- `com.eraf.notification.webhook.MessageCard`

### 6. Notification History (eraf-notification)
**구현 내용**:
- 알림 발송 이력 추적
- 상태 관리 (PENDING, SUCCESS, FAILED)
- 재시도 횟수 기록
- JPA Entity 기반

**주요 클래스**:
- `com.eraf.notification.history.NotificationHistory`
- `com.eraf.notification.history.NotificationHistoryRepository`
- `com.eraf.notification.history.NotificationStatus`

### 3. Outbox Pattern (eraf-outbox) ⭐
**구현 내용**:
- Transactional Outbox Pattern
- DB 트랜잭션과 메시지 발행의 원자성 보장
- 자동 폴링 스케줄러
- 재시도 로직

**주요 클래스**:
- `com.eraf.outbox.OutboxMessage`
- `com.eraf.outbox.OutboxPublisher`
- `com.eraf.outbox.OutboxScheduler`
- `com.eraf.outbox.OutboxStatus`

**DB 스키마**:
```sql
CREATE TABLE outbox_messages (
    id BIGSERIAL PRIMARY KEY,
    aggregate_type VARCHAR(255),
    event_type VARCHAR(255),
    payload TEXT,
    status VARCHAR(50),
    created_at TIMESTAMP,
    processed_at TIMESTAMP
);
```

### 4. WebSocket (eraf-websocket) ⭐

- Spring WebSocket + STOMP

**사용 예시**:

- `com.eraf.jpa.retention.DataRetentionPolicy`

**사용 예시**:
```java
@Entity
@DataRetentionPolicy(days = 90, dateField = "createdAt")
public class AuditLog extends BaseEntity {
    // 90일 후 자동 삭제
}
```

### 4. Workflow Engine (eraf-workflow) ⭐
**구현 내용**:
- 경량 워크플로우 엔진
- Step 기반 실행
- Context 공유
- 조건부 실행

**주요 클래스**:
- `com.eraf.workflow.WorkflowEngine`
- `com.eraf.workflow.WorkflowStep`

**사용 예시**:
```java
WorkflowEngine workflow = new WorkflowEngine();
workflow.addStep("validate", ctx -> validateOrder(ctx));
workflow.addStep("payment", ctx -> processPayment(ctx));
workflow.addStep("ship", ctx -> prepareShipment(ctx));
boolean success = workflow.execute(context);
```
