#### 1. ✅ eraf-observability - **유지 확정**

**기능**:

- MetricsUtil (LongCounter, DoubleHistogram)
- TracingUtil (Span, Trace)

**기술 스택**:
```java
import io.opentelemetry.api.metrics.*;
import io.opentelemetry.api.trace.*;
```

**eraf-actuator와의 차이점**:
| 항목 | eraf-observability | eraf-actuator |
|------|-------------------|---------------|
| 메트릭 백엔드 | **OpenTelemetry** | **Micrometer** |
| 표준 | CNCF (벤더 중립) | Spring Boot |
| 용도 | 분산 추적, 멀티 백엔드 | Spring Actuator 통합 |
| 클래스 수 | 4개 | 17개 |

**판정**:
- ❌ 중복 아님 (다른 기술 스택)
- ✅ **유지 필수**
- 📝 Excel에 추가 권장: "No.73 OpenTelemetry 통합"

---

#### 2. ✅ eraf-outbox - **유지 확정**

**기능**:
- Outbox Pattern 구현
- OutboxMessage Entity (JPA)
- OutboxService (범용)

**구현**:
```java
@Entity
@Table(name = "outbox_messages")
public class OutboxMessage {
    private String aggregateType;
    private String eventType;
    private String payload;  // 메시징 시스템 무관
    private OutboxStatus status;
}
```

**의존성**:
```xml
<!-- Kafka 의존성 없음 - JPA만 사용 -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
```

**Excel 대응**: No.56 "Outbox 패턴" (eraf-messaging-kafka 하위)

**판정**:
- ❌ Kafka 전용 아님 (범용 패턴)
- ✅ **유지 필수** (Kafka, RabbitMQ, 기타 모두 사용 가능)
- 📝 Excel 수정 권장: eraf-messaging-kafka 하위 → 독립 모듈
